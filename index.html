🌐 Classmates Board visible to everyone with this link

One-time setup needed: this board needs a free Firebase project to sync between devices (localStorage alone can't share data between your classmates' phones). Steps:
  1. Go to console.firebase.google.com → Create Project (free)
  2. Build → Firestore Database → Create database → Start in test mode
  3. Project settings → General → "Your apps" → Web app (</>) → copy the config object
  4. Paste it into firebaseConfig near the top of the script below
  5. Re-upload/host this file (GitHub Pages or Netlify, both free) and share that URL with classmates
